# Product Glossary

## Benchmark Mode

A clean evaluation path where models are judged on move quality, legality, and reproducibility without entertainment prompts contaminating gameplay.

## Showmatch Mode

A spectator-forward game mode where player banter, referee commentary, and character behavior are part of the experience.

## Interactive Mode

A mode where humans can join a game, control a seat, and hand control back to an LLM without restarting the match.

## Character Mode

A presentation layer that applies personality, voice, and avatar behaviors on top of chess gameplay.

## Chess Index

The planned public ladder of licensing-safe self-hosted models evaluated through chess.

## Referee

The rational mediator role, planned for `Gemma 4`, that reacts to deterministic engine rulings and helps keep chaotic matches understandable.

## Persona Layer

The part of the system that controls tone, character, banter, and presentation rather than move legality.

## Gameplay Layer

The part of the system that handles moves, rules, validation, state transitions, and benchmark integrity.
